# 4.1.8 가이드–구현 매핑

| 가이드 내용 | 구현 위치 |
|---|---|
| 공통 REST 호출 및 Context 전달 | `EligibilityClient`, `RequestContextFilter` |
| 연결·응답 타임아웃 | `RestClientConfiguration`, `EligibilityClientProperties` |
| 제한적 재시도/복구 | `EligibilityRetryClient` |
| 부적격 처리와 저장 | `ApplicationService` |
| 공통 오류 변환 | `GlobalExceptionHandler` |
| Mesh 전체 요청 타임아웃 | `deploy/istio/eligibility-timeout-virtual-service.yaml` |
| 교육용 지연/오류 | `DemoOnlyEligibilityBehaviorController`, `DemoOnlyBehaviorStore` |
| Context 수신 검증 | `ReceivedContextStore` |

## 정상 호출

```mermaid
sequenceDiagram
  participant U as Client
  participant F as RequestContextFilter
  participant A as ApplicationService
  participant R as EligibilityRetryClient
  participant C as EligibilityClient
  participant E as EligibilityController
  U->>F: POST /api/applications + Context
  F->>A: ServiceRequestContext 명시 전달
  A->>R: check(applicantId, context)
  R->>C: 첫 GET 시도
  C->>E: GET /internal/eligibilities/{id} + 3 headers
  E-->>C: EligibilityResult(eligible=true)
  C-->>A: 결과
  A-->>U: 저장 후 201 ACCEPTED
```

## 애플리케이션 또는 Mesh 타임아웃

```mermaid
sequenceDiagram
  participant A as ApplicationService
  participant R as EligibilityRetryClient
  participant C as EligibilityClient
  participant M as Mesh proxy (optional)
  participant E as EligibilityController
  A->>R: check
  R->>C: GET 시도
  C->>M: 앱 connect/read timeout 적용
  M->>E: Mesh 전체 요청 timeout 2s 적용 가능
  alt 앱 read timeout/연결 오류
    C-->>R: RetryableEligibilityCallException
    R->>C: 제한적 두 번째 시도
  else Mesh timeout
    M-->>C: HTTP 504
    C-->>R: RetryableEligibilityCallException
  end
  R-->>A: EligibilityServiceUnavailableException
  A-->>A: 신청 저장하지 않음
  Note over A: GlobalExceptionHandler가 일반화된 503 변환
```
